# پیگیر — نسخهٔ ۴.۰.۰

برنچ: `feature/vps-multitenant`، کد نسخه ۲۸. روی نسخهٔ قبلی نصب کنید؛ برای حفظ داده برنامه را حذف نکنید. استقرار واقعی VPS و انتقال دادهٔ شرکت فعلی در این مرحله انجام نشده‌اند.

- API شخصی با Docker/Ubuntu، پایگاه مستقل برای هر شرکت و پنل مدیریت سامانه.
- ورود گوشی با نشانی سرویس، کد شرکت، نام کاربری و رمز؛ حساب‌ها، داده و اعلان‌ها به همان شرکت محدودند.
- Firebase فقط برای رساندن اعلان باقی است. رئیس، دستیار و معاون‌های شرکت خودش را مدیریت می‌کند.
- ابزار پشتیبان، بازیابی روی volume تازه، بازیابی حساب مالک و انتقال SQL از Cloudflare همراه بسته است.

۲۰۳ آزمون اندروید، ۱۷ آزمون سرور VPS در کانتینر لینوکس و ۱۸ آزمون سازگاری سرویس قبلی موفق بودند؛ صفر خطای Lint و ۷۸ هشدار غیرمسدودکنندهٔ موجود. Docker Compose با HTTPS محلی، ساخت دو شرکت، جداسازی توکن/مصوبه، پشتیبان و بازیابی روی volume تازه بررسی شدند. تست مرورگر واقعی، VPS عمومی و تحویل اعلان روی گوشی واقعی انجام نشده است.

- `Peygir-4.0.0-debug.apk`: نسخهٔ اندروید ۸ به بالا.
- `Peygir-4.0.0-vps.zip`: بستهٔ مستقل نصب سرور، فونت/مجوز و راهنمای فارسی؛ نیاز به سورس اندروید برای ساخت سرور ندارد.
- `Peygir-4.0.0-source.zip`: سورس کامل و آزمون‌ها، بدون کلید و اطلاعات خصوصی.
- `SHA256SUMS-4.0.0.txt`: اثر انگشت سه بسته.

راهنمای نصب: `vps/README-fa.md`؛ گزارش: `verification/RESULTS.md` و `verification/vps-checks.json`.
