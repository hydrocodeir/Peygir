# پیگیر - نسخهٔ اندروید ۴.۳.۱

این به‌روزرسانی فقط برای اندروید است. فایل `Peygir-4.3.1-debug.apk` را روی نسخهٔ قبلی نصب کنید؛ پاک‌کردن اطلاعات یا ارتقای VPS لازم نیست. سرور فعلی و `Peygir-4.3.0-nginx-vps.zip` معتبرند.

در «تنظیمات ← ورود صوتی» انتخاب کنید:

- **لمس و پایان** - روش قبلی و پیش‌فرض؛ میکروفون، صحبت و دکمهٔ پایان.
- **نگه‌داشتن و صحبت** - میکروفون همان فیلد را نگه دارید و صحبت کنید؛ با رهاکردن، متن وارد می‌شود. برای لغو، انگشت را بیرون دکمه ببرید.

دکمهٔ ثابت ۴۸dp در سمت چپ فیلدهای فارسی، بازخورد ضبط و پیشرفت تبدیل دارد. در نخستین استفاده، مجوز میکروفون را بدهید و دوباره نگه دارید. TalkBack/صفحه‌کلید همچنان روش دارای دکمهٔ پایان را باز می‌کند. تبدیل روی گوشی است؛ صوت موقت حذف می‌شود و متن پیش از ذخیره قابل اصلاح است. روش انتخاب‌شده در پشتیبان هم حفظ می‌شود.

کد نسخه ۳۲؛ پایگاه ۷، پشتیبان ۵ و پروتکل ۲ ثابت‌اند. فایل‌ها: `Peygir-4.3.1-debug.apk`، `Peygir-4.3.1-source.zip` و `SHA256SUMS-4.3.1.txt`.

۲۳۷ تست اندروید موفق، صفر خطای Lint و ۸۲ هشدار غیرمسدودکننده. امضای قبلی و هم‌ترازی APK تأیید شدند. تست لمس با موتور صوتی ساختگی و رندر بومی انجام شد؛ ضبط واقعی و راحتی نگه‌داشتن روی گوشی هنوز بررسی نشده است.

# پیگیر - نسخهٔ ۴.۳.۰

هر دو بستهٔ سرور و اندروید را ارتقا دهید؛ کد APK برابر ۳۱ است. اطلاعات ورود، پوشهٔ خصوصی، volumeها و گواهی سرور را حفظ کنید و init را دوباره اجرا نکنید. پایگاه ۷، پشتیبان ۵ و پروتکل ۲ ثابت‌اند.

- نشانگر قرمز/سبز اتصال با متن و آیکون و جزئیات، تلاش مجدد افزایشی و تازه‌سازی دستی کنار تنظیمات.
- اعلان متمایز دعوت به جلسه و واگذاری مصوبه، با حذف تکراری و کنترل حساب/شرکت؛ در حالت باز یا پس‌زمینه از مسیر FCM.
- ورود تقویم روزانه/هفتگی نزدیک ساعت فعلی و حفظ جای اسکرول دستی هنگام تازه‌شدن داده.

۲۲۳ تست اندروید، ۲۸ تست VPS ویندوز/لینوکس و ۱۸ تست سرویس قبلی موفق؛ صفر خطای Lint و ۸۱ هشدار غیرمسدودکننده. Nginx و TLS محلی دوباره تست شدند. دریافت واقعی FCM و قطع/وصل واقعی شبکه روی گوشی نسخهٔ جدید باید پس از نصب بررسی شوند. توقف اجباری و محدودیت‌های اندروید ممکن است اعلان/تلاش پس‌زمینه را به تأخیر بیندازند.

فایل‌ها: `Peygir-4.3.0-debug.apk`، `Peygir-4.3.0-nginx-vps.zip` (مخصوص سرور فعلی)، `Peygir-4.3.0-vps.zip` (استقرار مستقل Caddy)، `Peygir-4.3.0-source.zip` و SHA256SUMS مربوط. در سرور فعلی، پس از جایگزینی فایل‌ها:

```bash
sudo bash vps/scripts/peygir-nginx.sh up -d --build --wait --wait-timeout 90 api
curl --fail http://127.0.0.1:18300/health
```

سلامت باید نسخهٔ ۴.۳ را برگرداند. سپس APK را روی برنامهٔ قبلی نصب کنید. راهنمای کامل: `vps/NGINX-fa.md`.
