# پیگیر - نسخهٔ ۴.۲.۰

کد نسخه ۳۰. ابتدا VPS را از بستهٔ ۴.۲ به‌روزرسانی کنید، سپس APK را روی برنامهٔ قبلی نصب کنید؛ برنامه یا داده‌ها را حذف نکنید. پایگاه گوشی خودکار به ۷ ارتقا می‌یابد. پشتیبان گوشی ۵، قالب‌های قبلی ۱ تا ۴ را می‌خواند.

- فرم مستقیم مصوبه و میکروفون کنار متن‌های عادی؛ بدون انتخاب جداگانهٔ نوشتن/صدا. فقط متن همان فیلد را بگویید؛ گفتن «عنوان» یا «مسئول» لازم نیست. تاریخ دستی انتخاب می‌شود.
- جست‌وجوی نام کوچک/فامیل و انتخاب مسئول در خود فرم؛ لمس کاربر، واگذاری به حساب اوست. تغییر نام مسئول، واگذاری قبلی را پاک می‌کند.
- شرکت‌کنندگان تایپی/صوتی و مخاطب جدید بدون حساب/دسترسی/اعلان؛ نام برای پیشنهادهای بعدی همان شرکت ذخیره و همگام می‌شود.
- نمای پیش‌فرض روزانه و جزئیات اختیاری جمع‌شده؛ گزینه‌های ثابت با صوت جست‌وجو و سپس انتخاب می‌شوند. رمز/کلید/نام کاربری/نشانی و ورودی فنی تایپی‌اند.

۲۱۸ تست اندروید، ۲۵ تست سرور ویندوز و Docker لینوکس و ۱۸ تست سرویس قبلی موفق‌اند. صفر خطای Lint و ۷۹ هشدار غیرمسدودکننده. امضا و هم‌ترازی APK تأیید شده‌اند. آزمون واقعی صدا/اعلان/ویجت روی گوشی و استقرار عمومی این نسخه انجام نشده‌اند.

- `Peygir-4.2.0-debug.apk`: اندروید ۸ به بالا.
- `Peygir-4.2.0-vps.zip`: بستهٔ مستقل سرور Docker و راهنمای فارسی.
- `Peygir-4.2.0-source.zip`: سورس و تست‌ها، بدون اطلاعات ورود و کلید خصوصی.
- `SHA256SUMS-4.2.0.txt`: اثر انگشت بسته‌ها.

راهنما: `vps/README-fa.md`؛ گزارش: `verification/RESULTS.md`.
