# پیگیر — نسخهٔ ۴.۱.۰

کد نسخه ۲۹؛ APK را روی نسخهٔ قبلی نصب کنید و سرور VPS را از بستهٔ ۴.۱ به‌روزرسانی کنید. برنامه را حذف نکنید. داده و پشتیبان قبلی سازگارند.

- کارت‌های تقویم روزانه و هفتگی، ساعت شروع/پایان تکراری ندارند.
- «کاربر جدید» با نام شخص، نام کاربری و نقش مدیر/دستیار/کاربر.
- ویرایش نام، نام کاربری و نقش؛ حذف حساب از منوی سه‌نقطه با قطع نشست‌ها و دسترسی ورود و حفظ مصوبات/سوابق.
- تغییر نقش یا نام کاربری نیازمند ورود دوباره است. حذف خود و آخرین مدیر فعال مسدود است. دستیار فقط حساب کاربران عادی را مدیریت می‌کند.

۲۰۹ آزمون اندروید، ۲۲ آزمون سرور روی لینوکس Docker و ۱۸ آزمون سرویس قبلی موفق؛ صفر خطای Lint و ۷۸ هشدار غیرمسدودکنندهٔ موجود. ساخت APK، امضا و هم‌ترازی تأیید شدند. روی VPS عمومی مستقر نشده و این نسخه روی گوشی واقعی آزمایش نشده است.

- `Peygir-4.1.0-debug.apk`: اندروید ۸ به بالا.
- `Peygir-4.1.0-vps.zip`: بستهٔ مستقل Docker/Ubuntu و راهنمای فارسی.
- `Peygir-4.1.0-source.zip`: سورس کامل، بدون داده یا کلید خصوصی.
- `SHA256SUMS-4.1.0.txt`: اثر انگشت بسته‌ها.

راهنما: `vps/README-fa.md`؛ گزارش: `verification/RESULTS.md`.
